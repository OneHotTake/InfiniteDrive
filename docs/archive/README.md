# Historical engineering archive

These documents preserve prior designs, investigations, sprint plans and dated
verification. They may describe removed classes, obsolete APIs or untested ideas.
They are not instructions for configuring or resetting a current server.

Use the [current documentation](../README.md), [architecture](../architecture.md)
and [developer guide](../dev-guide.md).

- `architecture/`: earlier architecture sketches and component inventories.
- `BACKLOG.md`, `TODO.md`, `HISTORY.md`: historical plans; revalidate open claims.
- Analysis, findings and sprint reports: investigation evidence.
- `overnight-hardening-report-2026-09-10.md`: dated 0.42.1 verification.
- `e2e-test-plan.md`, `SignedStreamService_Tests.md`: retired test plans.
